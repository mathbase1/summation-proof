One formula only · no guessed leap to cubes · no skipped algebra

Where the sum-of-squares formula actually comes from

12 + 22 + 32 + ··· + n2 = n(n + 1)(2n + 1)6

This page starts with what every symbol means, proves the one smaller fact we need, and then develops the cube idea as a natural consequence of asking how a growing shape changes from one stage to the next. Every substitution, cancellation, sign change and factor is shown before the final rule is checked independently.

Absolute starting point

1. What is the formula even saying?

Before proving anything, we must be completely clear about the sentence we are trying to prove.

Why I may switch from i to k

The letter is only the name of the counter. The sums Σi2 and Σk2, with the same starting and stopping values, both mean exactly the same list: 12 + 22 + ··· + n2. I use k later because k − 1 is convenient when comparing two neighbouring cubes.

What must be proved

Checking n = 4, or even checking one thousand separate values, does not prove the rule for every possible positive whole number. We need an argument that uses an arbitrary n, so the reasoning covers all positive whole numbers at once.

The only algebra rules we will use

Adding true equations

If A = B and C = D, then A + C = B + D. We add the left sides together and the right sides together.

Distributive law

a(b + c) = ab + ac. In reverse, ab + ac = a(b + c). This lets us expand brackets or take out a common factor.

Doing the same thing to both sides

If two quantities are equal, adding, subtracting, or dividing both by the same non-zero amount keeps them equal.

Replacing equal quantities

If T equals a formula, we may replace T by that formula anywhere. This is substitution.

Factors and factorising

A factor is one of the quantities being multiplied. Factorising means rewriting a sum as an equal multiplication; for example, 3x + 3y = 3(x + y).

Like terms

Terms are “like” when their letter parts match, such as 2k² and −5k². Their numerical coefficients may then be combined: 2k² − 5k² = −3k².

The problem we must solve before any cube appears

A long sum becomes easier if its terms can be written as changes between neighbouring stages, because neighbouring changes can cancel when added. We will therefore ask: what simple growing object has a one-step increase built from square-sized pieces? The answer will lead us to cubes; cubes will not be inserted as an unexplained trick.

The supporting fact

3. First derive 1 + 2 + ··· + n

We will need the ordinary sum later, so we must not simply quote it. Define

Tn = 1 + 2 + 3 + ··· + n.

The letter T is just a label for this total. It is not a new operation.

Write one copy in increasing order. Tn = 1 + 2 + 3 + ··· + (n − 1) + n
This is the definition of Tn.
Write the same numbers in reverse order. Tn = n + (n − 1) + (n − 2) + ··· + 2 + 1
Reordering a finite addition does not change its total. Both rows contain exactly the numbers 1 through n once each.
Add the two equations column by column. 2Tn = (1 + n) + (2 + n − 1) + (3 + n − 2) + ··· + (n + 1)
The left side is Tn + Tn = 2Tn. We also add the matching entries on the right.
Every displayed column equals n + 1. 1 + n = n + 1,   2 + (n − 1) = n + 1,   3 + (n − 2) = n + 1
These examples show the pattern, but examples alone are not the general proof.
Prove an arbitrary column, not just the first few. k + [n − (k − 1)] = k + (n − k + 1) = n + 1
The k-th entry of the increasing row is k. In the reversed row, moving k − 1 places from n leaves n − (k − 1) = n + 1 − k. Adding them gives k + n + 1 − k = n + 1, because +k and −k cancel. This proves the claim for every column position k from 1 to n.
There are n columns. 2Tn = n copies of (n + 1) = n(n + 1)
The original list contains n numbers: 1, 2, 3, …, n. Therefore the paired display has n columns.
Divide both sides by 2. Tn = n(n + 1)2
We had two copies of Tn. Dividing by 2 returns to one copy.
What if n is odd?

Nothing breaks. For n = 5, the middle 3 in the first copy sits above the middle 3 in the reversed copy, giving 3 + 3 = 6 = n + 1. We are pairing two copies of the list, not trying to pair numbers inside one copy.

Discovering the useful identity instead of guessing it

4. How would anyone naturally arrive at cubes?

This is the crucial question. Saying “look one power higher” is not a satisfying reason by itself. We will build the idea from a problem-solving goal, a cancellation pattern, and the geometry of growing shapes.

We are not allowed to begin with “try cubes”

At this point we know only that we want to add the square-sized terms 12, 22, …, n2. We now ask what kind of representation would make a long addition collapse to something short.

4A. First discover the cancellation mechanism we want

Imagine that G(k) means “the total size of some object at stage k”. Then G(k) − G(k − 1) means the amount added when the object grows from stage k − 1 to stage k.

[G(1) − G(0)] + [G(2) − G(1)] + [G(3) − G(2)] + [G(4) − G(3)] = G(1) − G(0) + G(2) − G(1) + G(3) − G(2) + G(4) − G(3) = −G(0) + [G(1) − G(1)] + [G(2) − G(2)] + [G(3) − G(3)] + G(4) = G(4) − G(0).
Why does G(1) cancel? +G(1) appears in the first bracket, and −G(1) appears in the second bracket.
They are equal quantities with opposite signs, so +G(1) − G(1) = 0.
Why does every interior stage cancel? For any interior index j, +G(j) occurs in G(j) − G(j − 1), while −G(j) occurs in G(j + 1) − G(j).
Thus each G(j), for 1 ≤ j ≤ n − 1, appears exactly once positively and exactly once negatively.
What survives? [G(1) − G(0)] + ··· + [G(n) − G(n − 1)] = G(n) − G(0).
G(0) has no earlier positive partner, and G(n) has no later negative partner. They are the two endpoints.
The search problem is now precise:

Can we find a simple object G whose one-step growth, G(k) − G(k − 1), contains the square term k2 together with only simpler correction terms that we already know how to add?

4B. Let growing geometry tell us which object to try

A term k2 counts a k by k area. So instead of randomly testing formulas, compare how familiar shapes change when their side length grows from k − 1 to k.

Grow a line

Total at stage k: k unit lengths.

k − (k − 1) = 1

The new part is a single unit: a constant, not a square-sized quantity.

Grow a square

Total at stage k: k2 unit squares.

k2 − (k − 1)2 = 2k − 1

The new border is one row of k cells plus one column of k − 1 further cells. Its size is linear in k.

Grow a cube

Total at stage k: k3 unit cubes.

k3 − (k − 1)3 = a shell

The shell is made from one-unit-thick sheets whose lengths are k or k − 1. Sheet counts multiply two lengths, so square terms appear naturally.

The natural reasoning, stated without jargon

Growing a line adds a point-sized piece. Growing a square adds an edge-shaped border. Growing a cube adds face-shaped sheets. Because our target terms k2 are areas, the first familiar growing object whose new layer is built from areas is a cube. That is why cubes are a systematic candidate—not a lucky guess.

4C. Why use k3 − (k − 1)3 rather than (k + 1)3 − k3?

Both expressions count the shell added between neighbouring cubes. The difference is only where we place the label k.

Backward difference — the version we choose

k3 − (k − 1)3

“Stage k minus the stage immediately before it.”

For k = 1, it starts with 13 − 03. For k = n, it ends with n3 − (n − 1)3. Adding all rows therefore leaves the clean endpoints n3 − 03 = n3.

Forward difference — also correct, but shifted

(k + 1)3 − k3

“The stage after k minus stage k.”

For k = 1, it starts with 23 − 13. For k = n, it ends with (n + 1)3 − n3. It works, but it leaves the less convenient endpoints (n + 1)3 − 1.

Nothing mystical happened in choosing k − 1

We want one row for each target square k2, beginning at k = 1 and ending at k = n. Writing “current stage minus previous stage” makes the first previous stage 0 and the final current stage n. It is simply the cleanest indexing choice.

4D. Count the cube shell exactly, with no overlap and no missing pieces

A k × k × k cube contains k3 unit cubes. The previous (k − 1) × (k − 1) × (k − 1) cube contains (k − 1)3. The difference is precisely the new shell.

Rigorous partition of the shell

Give each unit cube coordinates (x, y, z), where each coordinate is one of 1, 2, …, k. The old inner cube consists of cubes with x, y and z all at most k − 1. Therefore a cube is in the new shell exactly when at least one coordinate equals k.

  1. Piece A: z = k. The x-coordinate has k choices and y has k choices, so there are k × k = k2 cubes.
  2. Piece B: z is not k, but y = k. Then z has k − 1 choices and x has k choices, giving k(k − 1) cubes.
  3. Piece C: neither z nor y is k, so a shell cube not already counted must have x = k. Both y and z have k − 1 choices, giving (k − 1)2 cubes.

Coverage: every shell cube has at least one coordinate equal to k, so it enters A, B or C. No overlap: B explicitly excludes A, and C explicitly excludes both A and B. Every shell cube is therefore counted exactly once.

4E. Independent algebraic audit of the same identity

The geometric partition already proves the identity. We now multiply the brackets as an independent check, so the visual proof and the symbolic proof support one another.

Write the meaning of the cube. (k − 1)3 = (k − 1)(k − 1)(k − 1)
A cube means three identical factors.
Multiply the first two factors. (k − 1)(k − 1) = k·k + k(−1) + (−1)k + (−1)(−1)
There are four products: first–first, first–second, second–first and second–second.

The two −k terms combine to −2k.
Multiply by the remaining factor. (k2 − 2k + 1)(k − 1)
The first two factors have been replaced by an equal expression; the third factor remains.
Distribute k and then distribute −1. [k3 − 2k2 + k] + [−k2 + 2k − 1]

Collect like terms. (k − 1)3 = k3 − 3k2 + 3k − 1

Only the expression (k − 1)3 is replaced; the leading k3 stays where it is.

Subtracting the bracket means multiplying every inside term by −1. That reverses all four signs.

4G. Why this identity is useful even though it is not equal to k2 by itself

The shell identity contains the exact target term 3k2, plus only a linear correction −3k and a constant correction +1. Those corrections are deliberately manageable: we have already proved how to add 1 + 2 + ··· + n, and n copies of 1 simply add to n.

Start from the shell identity. k3 − (k − 1)3 = 3k2 − 3k + 1
This has been proved geometrically and audited algebraically.
Add 3k and subtract 1 on both sides. k3 − (k − 1)3 + 3k − 1 = 3k2
On the right, −3k + 3k = 0 and +1 − 1 = 0.
Divide by 3. k2 = k3 − (k − 1)3 + 3k − 13
This explicitly writes one square as a neighbouring-cube change plus two simpler corrections.
Make a long sum collapse using neighbouring changes
Seek growth containing an area term k2
Cube growth is made from area-sized sheets
Its corrections involve only Σk and n copies of 1
The cube method has now been motivated, not merely presented

We did not choose cubes because we already knew the answer. We first designed the cancellation we wanted, then examined the growth of lines, squares and cubes, identified cube growth as the first natural source of square-sized pieces, counted that shell exactly, and confirmed that the remaining correction terms were sums we could already handle.

Demystifying the final shape

7. Where did n, n + 1, 2n + 1, and 6 come from?

The final formula can look invented if we only see the last line. In the derivation, every factor has a traceable source.

The factor n

After combining terms, the numerator was 2n3 + 3n2 + n. Every term contains n, so we took n outside:

2n3 + 3n2 + n = n(2n2 + 3n + 1).

The factors n + 1 and 2n + 1

They came from factorising the remaining quadratic:

2n2 + 3n + 1 = (n + 1)(2n + 1).

Multiplying the right side back out gives 2n2 + n + 2n + 1 = 2n2 + 3n + 1.

The factor 2 in the denominator

It entered through the separately proved ordinary-sum formula Tn = n(n + 1)/2 and through placing all terms over a common denominator.

The factor 3 in the denominator

The cube identity produced 3Sn. After isolating that term, we divided by 3 to obtain one Sn. The denominator therefore became 2 × 3 = 6.

A useful memory story, not a substitute for the proof

The “2” comes from the formula for the ordinary sum. The “3” comes from the coefficient of the square term in the difference of cubes. Together they make the “6”.

Why the answer is always a whole number

The left side is a sum of whole-number squares, so the formula must produce a whole number. The product on top is always divisible by both 2 and 3. Because 2 and 3 have no common factor other than 1, being divisible by both means it is divisible by 2 × 3 = 6.

Divisibility by 2

n and n + 1 are consecutive whole numbers. One of any two consecutive whole numbers is even, so n(n + 1) contains a factor 2.

Divisibility by 3

If n leaves remainder 0 on division by 3, then n is divisible by 3. If n leaves remainder 1, then 2n + 1 leaves remainder 0. If n leaves remainder 2, then n + 1 is divisible by 3. So one of n, n + 1, and 2n + 1 always contains a factor 3.

A separate correctness check

8. Independent proof that the finished formula really generates the square sum

The derivation above tells us where the formula comes from. Now we verify it by a different idea: the formula must start correctly and must gain exactly the next square whenever n increases by 1.

Call the proposed formula

Fn = n(n + 1)(2n + 1)6.

Check the starting value n = 1

F1 = 1·2·36 = 66 = 1 = 12.

Before checking the gain: derive Fn−1 without a substitution jump

The formula Fn uses n as its input label. To avoid the confusing instruction “replace n by n − 1 everywhere” while n is still visible inside that replacement, first write the same rule with a neutral input letter r:

Fr = r(r + 1)(2r + 1)6.

The previous stage is obtained by setting r = n − 1. Every r-position receives the complete bracket n − 1.

(12 + ··· + (n − 1)2 + n2) − (12 + ··· + (n − 1)2) = n2.

Why this proves the formula for every n

The true square sum and the proposed formula both equal 1 at n = 1. To move from n = 1 to n = 2, both add 22. To move to n = 3, both add 32. At every later step, both add the same next square. Starting equal and making identical changes means they remain equal forever.

5

Common points of confusion

How could anyone have thought of using cubes?

The route is systematic. First seek neighbouring differences because they cancel when added. Then ask what growing object has a one-step increase made from areas, since k2 is an area. A line grows by a constant; a square grows by an edge-shaped linear border; a cube grows by face-shaped sheets whose counts involve products of two lengths. Cube growth is therefore the first simple geometric growth rule that naturally contains square terms.

Why not use (k + 1)3 − k3?

You may: it equals 3k2 + 3k + 1 and also telescopes. The backward form k3 − (k − 1)3 is chosen because, as k runs from 1 to n, the endpoints are 03 and n3. The forward form would leave 13 and (n + 1)3, creating more shifted algebra.

What exactly happens when k is replaced by k + 1?

Every occurrence of the placeholder is replaced by the complete bracket k + 1. Thus k − 1 becomes (k + 1) − 1 = k; k3 becomes (k + 1)3; 3k2 becomes 3(k + 1)2; and −3k becomes −3(k + 1). Replacing only some occurrences would not be a valid substitution.

Why does the next row contain −k3?

The next row uses counter value k + 1. Its “previous cube” is therefore [(k + 1) − 1]3 = k3. Because the identity subtracts the previous cube, that term is −k3. It cancels the +k3 at the start of the current row.

Why does the counter k disappear from the final answer?

k is a temporary counter used inside the addition. After every value k = 1, 2, …, n has been processed, the only free stopping number left is n. This is similar to saying “add every item in this box”: the temporary item label is gone after the total is formed.

Why are there n copies of +1?

We write one identity for each k-value. The allowed values are 1, 2, 3, …, n, which is a list of n values. Each identity contributes one +1, so their total is 1 + 1 + ··· + 1 with n terms, equal to n.

Why do the cubes cancel?

Every intermediate cube m3, where 1 ≤ m ≤ n − 1, appears once positively as the first term of m3 − (m − 1)3, and once negatively as the second term of (m + 1)3 − m3. Equal positive and negative copies sum to zero.

Why was it legitimate to factor 2n² + 3n + 1?

Factorising only rewrites an expression as an equal product. Multiplying (n + 1)(2n + 1) gives 2n2 + n + 2n + 1 = 2n2 + 3n + 1, so the two forms are exactly equal.

Could there be a different formula that also works?

Any expression that has the same value for every positive whole number is merely another algebraically equivalent form of the same function. The recurrence check shows the value is uniquely determined: start at 1 and add 22, then 32, and so on. There is no freedom to obtain a different numerical total at any stage.

Core conclusion: neighbouring differences were chosen because they telescope; cubes arose naturally because cube growth is made from area-sized sheets; and the final formula was then forced by that shell identity together with the separately proved ordinary-sum formula.
