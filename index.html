One formula only · no skipped algebra

Where the sum-of-squares formula actually comes from

12 + 22 + 32 + ··· + n2 = n(n + 1)(2n + 1)6

This page starts with what every symbol means, proves the one smaller fact we need, manufactures the square terms from ordinary multiplication, shows every cancellation, and then checks the final rule independently.

Absolute starting point

1. What is the formula even saying?

Before proving anything, we must be completely clear about the sentence we are trying to prove.

Why I may switch from i to k

The letter is only the name of the counter. The sums Σi2 and Σk2, with the same starting and stopping values, both mean exactly the same list: 12 + 22 + ··· + n2. I use k later because k − 1 is convenient when comparing two neighbouring cubes.

What must be proved

Checking n = 4, or even checking one thousand separate values, does not prove the rule for every possible positive whole number. We need an argument that uses an arbitrary n, so the reasoning covers all positive whole numbers at once.

The only algebra rules we will use

Adding true equations

If A = B and C = D, then A + C = B + D. We add the left sides together and the right sides together.

Distributive law

a(b + c) = ab + ac. In reverse, ab + ac = a(b + c). This lets us expand brackets or take out a common factor.

Doing the same thing to both sides

If two quantities are equal, adding, subtracting, or dividing both by the same non-zero amount keeps them equal.

Replacing equal quantities

If T equals a formula, we may replace T by that formula anywhere. This is substitution.

Factors and factorising

A factor is one of the quantities being multiplied. Factorising means rewriting a sum as an equal multiplication; for example, 3x + 3y = 3(x + y).

Like terms

Terms are “like” when their letter parts match, such as 2k² and −5k². Their numerical coefficients may then be combined: 2k² − 5k² = −3k².

The key idea

The difference between two neighbouring cubes, k3 and (k − 1)3, contains a k2 term. Adding all those neighbouring-cube differences makes almost every cube cancel. That gives one equation containing the square sum we want.

The supporting fact

3. First derive 1 + 2 + ··· + n

We will need the ordinary sum later, so we must not simply quote it. Define

Tn = 1 + 2 + 3 + ··· + n.

The letter T is just a label for this total. It is not a new operation.

Write one copy in increasing order. Tn = 1 + 2 + 3 + ··· + (n − 1) + n
This is the definition of Tn.
Write the same numbers in reverse order. Tn = n + (n − 1) + (n − 2) + ··· + 2 + 1
Reordering a finite addition does not change its total. Both rows contain exactly the numbers 1 through n once each.
Add the two equations column by column. 2Tn = (1 + n) + (2 + n − 1) + (3 + n − 2) + ··· + (n + 1)
The left side is Tn + Tn = 2Tn. We also add the matching entries on the right.
Every column equals n + 1. 1 + n = n + 1,   2 + (n − 1) = n + 1,   3 + (n − 2) = n + 1
In each column, the amount added to the first number is exactly what is needed to reach n + 1.
There are n columns. 2Tn = n copies of (n + 1) = n(n + 1)
The original list contains n numbers: 1, 2, 3, …, n. Therefore the paired display has n columns.
Divide both sides by 2. Tn = n(n + 1)2
We had two copies of Tn. Dividing by 2 returns to one copy.
What if n is odd?

Nothing breaks. For n = 5, the middle 3 in the first copy sits above the middle 3 in the reversed copy, giving 3 + 3 = 6 = n + 1. We are pairing two copies of the list, not trying to pair numbers inside one copy.

Manufacturing square terms

4. Why compare neighbouring cubes?

Our target contains k2. A useful trick is to look one power higher, at k3, and subtract the previous cube. The leading k3 parts cancel, leaving an expression whose highest power is k2.

This is the reason cubes appear

We are not claiming the square sum is “about cubes” by magic. We deliberately choose a difference of cubes because multiplying it out produces a square term, and consecutive differences later cancel when added.

First derive (k − 1)3 with every multiplication shown

By definition, a cube means three identical factors. Geometrically, a k × k × k cube has k layers; each layer contains k × k unit cubes, so the total is k × k × k = k3.

(k − 1)3 = (k − 1)(k − 1)(k − 1).
Multiply the first two brackets. (k − 1)(k − 1)
Each term in the first bracket multiplies each term in the second bracket.
Write all four products. k·k + k·(−1) + (−1)·k + (−1)·(−1)
The four products are first–first, first–second, second–first, and second–second.
Evaluate those products. k2 − k − k + 1
k·k = k2; k·(−1) = −k; (−1)·k = −k; and (−1)(−1) = +1.
Combine the two identical −k terms. (k − 1)2 = k2 − 2k + 1
−k − k = −2k.
Multiply by the remaining (k − 1). (k − 1)3 = (k2 − 2k + 1)(k − 1)
We had three factors. The first two have been replaced by their equal expanded form.
Distribute the k. k(k2 − 2k + 1) = k3 − 2k2 + k
k·k2 = k3, k·(−2k) = −2k2, and k·1 = k.
Distribute the −1. −1(k2 − 2k + 1) = −k2 + 2k − 1
Multiplying every term by −1 reverses its sign.
Add the two distributed parts. k3 − 2k2 + k − k2 + 2k − 1
This is exactly the distributive law applied to both terms of the second bracket.
Collect like terms. (k − 1)3 = k3 − 3k2 + 3k − 1
−2k2 − k2 = −3k2, and k + 2k = 3k.

Now subtract that smaller cube from k3

k3 − (k − 1)3
This means “larger cube minus the immediately previous cube”.
= k3 − [k3 − 3k2 + 3k − 1]
Replace (k − 1)3 by the expanded expression just proved.
= k3 − k3 + 3k2 − 3k + 1
The minus sign outside the square bracket multiplies every term inside by −1, so every sign inside reverses.
= 3k2 − 3k + 1
k3 − k3 = 0, so those two terms disappear.
k3 − (k − 1)3 = 3k2 − 3k + 1.

A visual meaning of the same identity

A k × k × k cube contains k3 unit cubes. Remove the inner (k − 1) × (k − 1) × (k − 1) cube. The remaining shell can be split into three non-overlapping slabs.

Why the visual and algebra agree

The shell count is k2 + k(k − 1) + (k − 1)2. Expanding those three pieces gives k2 + (k2 − k) + (k2 − 2k + 1) = 3k2 − 3k + 1. That is exactly the algebraic identity above.

The full derivation

6. Now do exactly the same thing for an arbitrary n

Define the two totals we will use. The small n written below S or T is a subscript: it records the stopping value and is not multiplication.

Sn = 12 + 22 + ··· + n2
Tn = 1 + 2 + ··· + n = n(n + 1)2

6A. Write the cube identity for every counter value

For k = 1:   13 − 03 = 3·12 − 3·1 + 1
For k = 2:   23 − 13 = 3·22 − 3·2 + 1
For k = 3:   33 − 23 = 3·32 − 3·3 + 1
Continue in the same pattern …
For k = n:   n3 − (n − 1)3 = 3n2 − 3n + 1

6B. Add every left side and every right side

Adding equal equations is legal: if each left side equals its matching right side, the total of all left sides equals the total of all right sides.

The left side

(13 − 03) + (23 − 13) + ··· + (n3 − (n − 1)3)

To expose the cancellation, regroup equal cube powers. Finite addition may be regrouped without changing the total:

−03 + (13 − 13) + (23 − 23) + ··· + ((n − 1)3 − (n − 1)3) + n3.

Every bracket of the form a − a equals zero. Also 03 = 0. Therefore:

The total left side is n3.

The right side

[3·12 − 3·1 + 1] + [3·22 − 3·2 + 1] + ··· + [3n2 − 3n + 1]

Now collect the same kinds of terms:

3(12 + 22 + ··· + n2) − 3(1 + 2 + ··· + n) + (1 + 1 + ··· + 1).

Square column

Every square has a factor 3, so 3·12 + 3·22 + ··· + 3n2 = 3Sn.

Ordinary-number column

−3·1 − 3·2 − ··· − 3n = −3Tn.

Ones column

There is one +1 for each k-value 1, 2, …, n. That is n copies of 1, so the total is n.

The total right side is 3Sn − 3Tn + n.

6C. Equate the two totals

The summed left side and summed right side came from adding the two sides of the same collection of true equations, so they are equal:

n3 = 3Sn − 3Tn + n.

6D. Isolate Sn one legal move at a time

n3 = 3Sn − 3Tn + n
This is the equation obtained by summing the cube identity.
Add 3Tn to both sides. n3 + 3Tn = 3Sn + n
On the right, −3Tn + 3Tn = 0.
Subtract n from both sides. n3 + 3Tn − n = 3Sn
On the right, +n − n = 0.
Swap the two sides for readability. 3Sn = n3 + 3Tn − n
If A = B, then B = A. This does not change the statement.
Substitute the separately proved ordinary-sum formula. 3Sn = n3 + 3n(n + 1)2 − n
Tn equals n(n + 1)/2, so replacing Tn by that equal quantity is legal.
Put every term over the common denominator 2. n3 = 2n32,   n = 2n2
Multiplying a quantity by 2/2 does not change it because 2/2 = 1.
Combine the three fractions. 3Sn = 2n3 + 3n(n + 1) − 2n2
Fractions with the same denominator are added or subtracted by combining their numerators while keeping the denominator.
Expand 3n(n + 1). 3n(n + 1) = 3n·n + 3n·1 = 3n2 + 3n
This is the distributive law.
Substitute that expansion into the numerator. 3Sn = 2n3 + 3n2 + 3n − 2n2
We replaced 3n(n + 1) by an equal expanded expression.
Combine 3n − 2n. 3Sn = 2n3 + 3n2 + n2
Three copies of n minus two copies of n leave one copy of n.
Factor one n out of every numerator term. 2n3 + 3n2 + n = n(2n2 + 3n + 1)
n·2n2 = 2n3, n·3n = 3n2, and n·1 = n.
Factor the quadratic 2n2 + 3n + 1. 2n2 + 3n + 1 = 2n2 + 2n + n + 1
We split 3n into 2n + n. Nothing has changed because 2n + n = 3n.
Group the first pair and second pair. (2n2 + 2n) + (n + 1)
Parentheses only show the grouping we plan to factor.
Factor each group. 2n(n + 1) + 1(n + 1)
2n2 + 2n = 2n(n + 1), and n + 1 = 1(n + 1).
Factor out the common bracket (n + 1). 2n(n + 1) + 1(n + 1) = (n + 1)(2n + 1)
This is the distributive law in reverse: ax + bx = (a + b)x.
Place the factors back into the fraction. 3Sn = n(n + 1)(2n + 1)2
We have only rewritten the numerator as an equal product.
Divide both sides by 3. Sn = n(n + 1)(2n + 1)2 ÷ 3
The left side 3Sn divided by 3 is Sn.
Rewrite division by 3 as multiplication by 1/3. Sn = n(n + 1)(2n + 1)2 × 13
Dividing by a non-zero number is the same as multiplying by its reciprocal.
Multiply the denominators. Sn = n(n + 1)(2n + 1)2 × 3 = n(n + 1)(2n + 1)6
2 × 3 = 6. This is the exact origin of the denominator 6.
Therefore, for every positive whole number n,
12 + 22 + ··· + n2 = n(n + 1)(2n + 1)6.

Demystifying the final shape

7. Where did n, n + 1, 2n + 1, and 6 come from?

The final formula can look invented if we only see the last line. In the derivation, every factor has a traceable source.

The factor n

After combining terms, the numerator was 2n3 + 3n2 + n. Every term contains n, so we took n outside:

2n3 + 3n2 + n = n(2n2 + 3n + 1).

The factors n + 1 and 2n + 1

They came from factorising the remaining quadratic:

2n2 + 3n + 1 = (n + 1)(2n + 1).

Multiplying the right side back out gives 2n2 + n + 2n + 1 = 2n2 + 3n + 1.

The factor 2 in the denominator

It entered through the separately proved ordinary-sum formula Tn = n(n + 1)/2 and through placing all terms over a common denominator.

The factor 3 in the denominator

The cube identity produced 3Sn. After isolating that term, we divided by 3 to obtain one Sn. The denominator therefore became 2 × 3 = 6.

A useful memory story, not a substitute for the proof

The “2” comes from the formula for the ordinary sum. The “3” comes from the coefficient of the square term in the difference of cubes. Together they make the “6”.

Why the answer is always a whole number

The left side is a sum of whole-number squares, so the formula must produce a whole number. The product on top is always divisible by both 2 and 3. Because 2 and 3 have no common factor other than 1, being divisible by both means it is divisible by 2 × 3 = 6.

Divisibility by 2

n and n + 1 are consecutive whole numbers. One of any two consecutive whole numbers is even, so n(n + 1) contains a factor 2.

Divisibility by 3

If n leaves remainder 0 on division by 3, then n is divisible by 3. If n leaves remainder 1, then 2n + 1 leaves remainder 0. If n leaves remainder 2, then n + 1 is divisible by 3. So one of n, n + 1, and 2n + 1 always contains a factor 3.

A separate correctness check

8. Independent proof that the finished formula really generates the square sum

The derivation above tells us where the formula comes from. Now we verify it by a different idea: the formula must start correctly and must gain exactly the next square whenever n increases by 1.

Call the proposed formula

Fn = n(n + 1)(2n + 1)6.

Check the starting value n = 1

F1 = 1·2·36 = 66 = 1 = 12.

Check the amount gained from n − 1 to n

The actual square sum gains n2 at this step, because

(12 + ··· + (n − 1)2 + n2) − (12 + ··· + (n − 1)2) = n2.

Now calculate the gain in the proposed formula.

Fn−1 = (n − 1)n(2(n − 1) + 1)6
Replace n by n − 1 everywhere in the formula.
2(n − 1) + 1 = 2n − 2 + 1 = 2n − 1
Distribute the 2, then combine −2 + 1.
Fn−1 = (n − 1)n(2n − 1)6
Substitute the simplified last factor.
Fn − Fn−1 = n(n + 1)(2n + 1) − (n − 1)n(2n − 1)6
The denominators are the same, so subtract the numerators.
= n[(n + 1)(2n + 1) − (n − 1)(2n − 1)]6
Both numerator terms contain n, so factor it out.
(n + 1)(2n + 1) = 2n2 + 3n + 1
The four products are 2n2, n, 2n, and 1; n + 2n = 3n.
(n − 1)(2n − 1) = 2n2 − 3n + 1
The four products are 2n2, −n, −2n, and +1; −n − 2n = −3n.
(2n2 + 3n + 1) − (2n2 − 3n + 1) = 6n
Removing the second bracket changes its signs: 2n2 + 3n + 1 − 2n2 + 3n − 1 = 6n.
Fn − Fn−1 = n(6n)6 = n2
The factor 6 cancels, leaving n·n = n2.
Why this proves the formula for every n

The true square sum and the proposed formula both equal 1 at n = 1. To move from n = 1 to n = 2, both add 22. To move to n = 3, both add 32. At every later step, both add the same next square. Starting equal and making identical changes means they remain equal forever.

Common points of confusion

Why does the counter k disappear from the final answer?

k is a temporary counter used inside the addition. After every value k = 1, 2, …, n has been processed, the only free stopping number left is n. This is similar to saying “add every item in this box”: the temporary item label is gone after the total is formed.

Why are there n copies of +1?

We write one identity for each k-value. The allowed values are 1, 2, 3, …, n, which is a list of n values. Each identity contributes one +1, so their total is 1 + 1 + ··· + 1 with n terms, equal to n.

Why do the cubes cancel?

Every intermediate cube m3, where 1 ≤ m ≤ n − 1, appears once positively as the first term of m3 − (m − 1)3, and once negatively as the second term of (m + 1)3 − m3. Equal positive and negative copies sum to zero.

Why was it legitimate to factor 2n² + 3n + 1?

Factorising only rewrites an expression as an equal product. Multiplying (n + 1)(2n + 1) gives 2n2 + n + 2n + 1 = 2n2 + 3n + 1, so the two forms are exactly equal.

Could there be a different formula that also works?

Any expression that has the same value for every positive whole number is merely another algebraically equivalent form of the same function. The recurrence check shows the value is uniquely determined: start at 1 and add 22, then 32, and so on. There is no freedom to obtain a different numerical total at any stage.

Core conclusion: the formula is forced by the difference-of-neighbouring-cubes identity and the separately proved ordinary-sum formula.
